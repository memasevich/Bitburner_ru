# JavaScript с нуля — учебная лаборатория

Небольшой самостоятельный интерактивный учебник на русском языке для новичков и игроков Bitburner. Проект вдохновлён тематикой открытых руководств по JavaScript, но объяснения и структура написаны отдельно.

## Локальный запуск

Откройте `index.html` в браузере. Для локального просмотра можно также запустить любой статический HTTP-сервер из этой папки. Сборка и установка зависимостей не нужны.

## Публикация

Содержимое этой папки публикуется отдельным GitHub Pages workflow по адресу `https://memasevich.github.io/Bitburner_ru/learn-js-ru/`. GitHub Pages в репозитории должен быть включён с источником **GitHub Actions**. Для собственного домена владелец должен отдельно настроить домен и DNS.

## Безопасность примеров

Редактор запускает JavaScript в iframe-песочнице без доступа к origin страницы, сети и файловой системе. Не запускайте незнакомый код вне этой песочницы.
