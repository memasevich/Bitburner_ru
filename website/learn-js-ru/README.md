# JavaScript с нуля — учебная лаборатория

Небольшой самостоятельный интерактивный учебник на русском языке для новичков и игроков Bitburner. Проект вдохновлён тематикой открытых руководств по JavaScript, но объяснения и структура написаны отдельно.

## Авторство и источники

Курс создан Memasevich. При подготовке программы и объяснений использованы темы и учебные материалы [Learn-js.org](https://www.learn-js.org/en/Welcome) и [Programiz](https://www.programiz.com/javascript/get-started). Уроки на этом сайте адаптированы на русском языке, дополнены собственными примерами и практическими параллелями с Bitburner; это не официальный перевод и не копия указанных сайтов. Логотип Memasevich и ссылки на источники размещены в верхней части курса.

## Локальный запуск

Откройте `index.html` в браузере. Для локального просмотра можно также запустить любой статический HTTP-сервер из этой папки. Сборка и установка зависимостей не нужны.

## Публикация

Содержимое этой папки публикуется отдельным GitHub Pages workflow по адресу `https://memasevich.github.io/Bitburner_ru/learn-js-ru/`. Для собственного домена владелец должен отдельно настроить домен и DNS.

## Безопасность примеров

Редактор запускает JavaScript в отдельном Worker внутри iframe-песочницы без доступа к origin страницы, сети и файловой системе. Доступа к DOM в этой учебной среде нет. Бесконечный цикл не блокирует интерфейс: выполнение можно остановить вручную, а через 3 секунды оно прерывается автоматически. Не запускайте незнакомый код вне этой песочницы.

## Работа с курсом

В курсе 54 урока с примерами и параллелями с Bitburner. Пример можно читать в тексте урока или открыть в редакторе. Большой редактор показывает код и консоль рядом; на телефоне панели расположены друг под другом. Ctrl+Enter запускает код, Tab добавляет отступ, Shift+Tab переводит фокус к предыдущему элементу, Escape сворачивает большое окно.

Прогресс, последний открытый урок и отдельный черновик каждого урока хранятся в localStorage этого браузера. Отметка о прохождении не меняет код. «Вернуть пример» сбрасывает черновик текущего урока. Если браузер запрещает запись, интерфейс сообщает, что черновик доступен только в текущей вкладке.
